# سینوا — Cineva

قالب شروع فول‌استک فارسی برای آرشیو فیلم و سریال با Next.js، TypeScript، PostgreSQL و Prisma.

## پیش‌نیازها

- Node.js نسخه 20.9 یا بالاتر
- Docker Desktop (برای اجرای دیتابیس محلی)
- npm

## راه‌اندازی در ویندوز

در پوشه پروژه PowerShell یا ترمینال VS Code را باز کن:

```powershell
npm install
Copy-Item .env.example .env
docker compose up -d
npx prisma generate
npx prisma migrate dev --name init
npm run db:seed
npm run dev
```

سپس سایت را در `http://localhost:3000` باز کن.

اگر از CMD استفاده می‌کنی، برای ساخت `.env` این را اجرا کن:

```cmd
copy .env.example .env
```

## دستورهای مفید

```bash
npm run dev          # اجرای توسعه
npm run db:studio    # پنل مشاهده دیتابیس
npm run db:seed      # افزودن داده‌های نمونه
npm run build        # ساخت نسخه production
```

## مسیرهای موجود

- `/` صفحه اصلی
- `/browse` آرشیو و جست‌وجو
- `/browse?type=MOVIE` فیلم‌ها
- `/browse?type=SERIES` سریال‌ها
- `/title/interstellar` صفحه جزئیات نمونه
- `/support` صفحه معرفی حمایت
- `/api/movies` API فهرست فیلم‌ها و سریال‌ها

## وضعیت فعلی

این خروجی یک اسکلت اجرایی و نقطه شروع واقعی است، نه محصول آماده انتشار. صفحه‌ها با داده نمونه نمایش داده می‌شوند و پس از راه‌اندازی دیتابیس، داده‌های PostgreSQL را می‌خوانند. API فهرست عناوین پیاده‌سازی شده است.

مواردی که باید پیش از تحویل نهایی پیاده‌سازی و تست شوند:
- احراز هویت و نقش‌های کاربری/مدیریت
- CRUD امن در پنل ادمین برای عنوان‌ها، قسمت‌ها، لینک‌ها و بازیگران
- ثبت نظر با اعتبارسنجی، محدودیت نرخ و تأیید مدیر
- پلیر واقعی با منبع ویدیویی مجاز و پشتیبانی زیرنویس
- اتصال درگاه پرداخت واقعی و بررسی callback سمت سرور
- تست واحد/یکپارچه، دسترس‌پذیری و بررسی امنیتی
- سیاست حریم خصوصی، شرایط استفاده و مجوز محتوای نمایش‌داده‌شده

## نکات

- آدرس‌های پوستر نمونه از TMDB استفاده می‌کنند؛ در صورت نیاز باید مجوزها و شرایط استفاده از تصاویر را بررسی کنی.
- لینک دانلود و ویدیوی واقعی در داده نمونه قرار نگرفته‌اند.
- اطلاعات پرداخت و اسرار را در مخزن Git یا کد سمت مرورگر قرار نده.
- رمز دیتابیس در `.env.example` فقط برای توسعه محلی است و برای محیط عمومی مناسب نیست.
